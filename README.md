# hajimekita

A mini game I wrote when I was feeling bored
There might be many bugs. If so, please feel free to raise them in the comment section
The link for the beta version is https://eternaltat.github.io/hajimekita/
Welcome to enjoy the game for free!

If you enjoy this little game, you might also consider sponsoring it
Afterwards, your ID will be added to the list of sponsors already existing in the game

The title "hajimekita" of the game refers to the two main characters in the game
It is named based on the first two characters of their real-life social media account IDs
"Hajime" in Japanese means "創(creation)", and it is the ID of the game's female protagonist's real-life social media account.
"Kita" in Japanese means "北(north)", and similarly, it is the ID of the game's male protagonist's real-life social media account.

Thank you for your playing
